# Side chats

Use `/side` in an existing Codex or Claude conversation to open a separate conversation with its provider context. Use `/side your question` to send the first message immediately. Keep the original provider selected; conversation forks cannot cross provider instances. Other providers do not support this command.

Side chats share the original project and worktree, so file changes affect the same workspace. Attach files after opening the side chat.

On mobile and narrow browser windows, side chats open as full-screen conversations. Use **Related chats** in the thread header to return to the original conversation or switch between children and siblings.

On desktop and wide browser windows, `/side` opens a tab beside the original conversation. You can also create one from the right panel's **+** menu. Closing a tab keeps the conversation saved; reopen it from the **+** menu or **Related chats** above the transcript. Use **Open full view** for attachments, approvals, or questions that need your answer. Every side chat also appears in the normal thread list, including after restarting the app.

Returning to another conversation keeps the side chat saved. To delete it on mobile, open Related chats, open the current conversation's actions, and choose **Delete side chat**. This asks for confirmation. Deleting a parent keeps its child conversations available in the thread list.

If the first message cannot be submitted, its text remains in the side chat's composer so you can retry.
