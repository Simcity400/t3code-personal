# Native agent transcripts

When a provider delegates work to its own agents, open the thread's agent view to
inspect their transcripts. Select an agent to read the messages and tool activity
reported by the provider, then return to the main conversation to continue working.

Availability and detail depend on what the provider reports. An agent without a
reported transcript may still appear with its status. This view covers native
provider delegation; it does not create a separate cross-provider workflow.
